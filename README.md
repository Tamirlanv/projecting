# Подготовка к экзамену по проектированию

Открой `index.html` двойным щелчком. Установка пакетов и интернет для работы сайта не нужны.

Если браузер ограничивает сохранение данных при открытии файла, запусти из папки `projecting`:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем открой http://127.0.0.1:4173. Также можно выполнить `npm start` — установка зависимостей не требуется.

## Что внутри

- 30 билетов с исходными формулировками: два теоретических вопроса и практическое задание.
- 60 конспектов: определение, основные тезисы, пример и типичная ошибка.
- 30 практических разборов с планом, проверками, готовыми SVG-диаграммами и скачиваемым исходником PlantUML. Все схемы доступны офлайн; для изменения исходников нужен отдельный редактор PlantUML.
- 60 тестовых вопросов с объяснениями, выбором тем, случайным порядком и историей результатов.
- Поиск, фильтры, избранное, заметки и повторение через 10 минут / 1 день / 3 дня после отметки. Это простая схема повторения, а не адаптивный алгоритм.
- Случайный билет с таймером, черновиком и ручной самооценкой по критериям 30 + 30 + 40.

Отметка «Знаю» учитывается в прогрессе. Правильный ответ в тесте сам по себе не помечает тему изученной; ошибка добавляет её в повторение. После выбора отметки можно остаться на карточке или нажать «Дальше».

Прогресс хранится в `localStorage` текущего браузера и адреса сайта. Данные при открытии файла и через локальный сервер могут храниться раздельно. В «Материалах и твоих данных» доступны экспорт и импорт JSON. Импорт объединяет отметки и заметки; импортированные значения одного вопроса заменяют прежние.

Клавиши: `/` — поиск; пробел — раскрыть ответ, когда фокус вне кнопок и полей; стрелки влево/вправо — соседняя карточка. На вкладках билета стрелки переключают вкладки.

## Материалы

Вопросы перенесены из `Билеты_проектирование.docx`; копия находится в `assets/original-tickets.docx`. Критерии оценивания взяты из соседнего файла `Критерии_оценивания_экзамена проект.docx`.

Ответы, практические решения и тесты — авторские учебные материалы, а не официальный ключ преподавателя. Источники для сверки указаны в конспектах и окне материалов. Для CMM используется SW-CMM v1.1; для сравнения представлений CMMI — исторический контекст 1.x. Варианты практических решений явно описывают допущения.

## Проверка

```sh
npm test
```

Тесты используют встроенные возможности Node.js и имитацию DOM для проверки данных и логики: все билеты и ответы, поиск, фильтры, сохранение/повторение, оценивание тестов, таймер, рубрика 100 баллов, резервные копии и безопасный вывод текста. Они не заменяют визуальную проверку в настоящем браузере.

Файлы сайта не выполняют сетевых запросов. Внешние ссылки на стандарты и материалы открываются только при переходе по ним.

Готовые схемы находятся в `assets/diagrams`. Если меняется `practice.js`, выполни `node scripts/export-diagrams.mjs`, затем отрисуй `.puml` с помощью PlantUML: `java -jar /путь/к/plantuml.jar -tsvg -Playout=smetana -charset UTF-8 assets/diagrams`. PlantUML нужен только для обновления схем, а не для запуска сайта.
